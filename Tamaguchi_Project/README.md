# Cozy Creature Survival

## Description
Cozy Creature Survival is a Unity-based Android game project inspired by Tamagotchi-style virtual pet care in a relaxed survival setting.

This project is in very early development and currently represents an incomplete prototype.

## Current Features
- petStat system
  - Tracks basic pet attributes such as hunger, energy, and mood.

## Planned Features (Not Implemented Yet)
- Feeding system
- Day/night cycle
- Environment effects
- Interaction system
- Save/load system

## Gameplay Vision
The intended experience is chill, slow-paced, and low pressure. The player should feel encouraged to check in over time, care for the creature, and progress gradually without strict penalties or intense challenge.

## Project Status
- Early prototype
- Core systems are incomplete
- Structure and features are subject to change during development

## Installation
### Unity Project Setup
1. Clone this repository.
2. Open Unity Hub.
3. Add and open the Tamaguchi_Project folder.
4. Let Unity import and recompile project assets.
5. Build for Android from Unity when needed.

### Optional APK Build Notes
1. In Unity, switch platform to Android in Build Settings.
2. Configure Android Player Settings (package name, SDK settings, signing if required).
3. Build APK for testing on a device.
